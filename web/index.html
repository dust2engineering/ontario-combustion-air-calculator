Scope — read this

This tool covers the tight-construction path of CSA B149.1 Clause 8: Table 8.1 (with draft control, up to 400 MBH) and the Clause 8.4 formulas above 400 MBH. The Table 8.2 grid and the loose-construction volume tables (8.3/8.4) are not reproduced — their full grids are not publicly verifiable, and this tool does not invent code data. Free area means net area after louvre and grille blockage.
